% Design, Fig. arch: the overall architecture. One loop per window on every node:
%   (1) a GPU takes the next sector of the window from the sector store in host memory, (2) applies the gates of the
%   window to it (branch, merge, truncate), (3) meanwhile the row selector samples the live terms and chooses the rows
%   of the next window, (4) the GPU splits its output by these rows and the pieces return to the store as sectors of
%   the next window, (5) at the window boundary the sectors that other nodes own move to them.
% Colors: one per sector (blue 00, green 01, yellow 10, violet 11), khaki GPUs, yellow actions, green the choice made
% at run time, one tint per node.
