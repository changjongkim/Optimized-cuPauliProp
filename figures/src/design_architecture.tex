% Overall architecture of SectorQ (Section 3.1): the cycle that the scheme consists of.
%   top     the planner (rank 0) turns the circuit into windows and gives every window its parity rows
%   middle  one window: every node keeps its sectors in host memory and its GPUs take them one at a time;
%           nothing moves between nodes while the window runs
%   bottom  the window boundary: the outputs, already divided by the rows of the next window, go to the
%           nodes that own the next sectors; checkpoint; then the next window
