% Sector-at-a-time execution (Section 3.4): what the host memory and one GPU hold while a window runs, and
% how a sector that outgrows the GPU is halved. Data structures of src/engine/pp_engine.cpp: a sector is a
% list of fixed-size chunks (262,144 terms each, pinned once and reused, ChunkPool); a worker keeps two
% term buffers of 20% of the GPU memory each and the rest as scratch space (Worker::init, expShare = 0.2):
% 190 million terms per buffer on 36 GB. Worker::process loads a sector, applies the operations of the
% window, splits the sector by one more row of the window when the next operation does not fit
% (splitCurrent), and divides the output by the rows of the next window into the tails of the next sectors.
% Key value: 11.9 billion terms at a window boundary on 16 GPUs (campaign g, eng.ki.1e-6.g16; README 4.4).
